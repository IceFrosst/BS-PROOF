# History

Closed audits, sign-offs, archives and the dated project log. **Nothing here
is a task list.**

These files are snapshots of what was wrong at a moment in time, kept because the
reasoning is worth reading and because a fixed problem should be findable. Every
one carries a banner saying when it closed.
